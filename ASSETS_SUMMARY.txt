================================================================================
  快速开始
================================================================================

1️⃣ 查看所有可用角色类型：
   $ node query_characters.mjs types

2️⃣ 查看统计信息：
   $ node query_characters.mjs stats

3️⃣ 获取一个随机女法师：
   $ node query_characters.mjs random mage f

4️⃣ 查看某个角色的所有表情：
   $ node query_characters.mjs emotions Angela-mage-001

5️⃣ 搜索特定角色：
   $ node query_characters.mjs search lyuba
